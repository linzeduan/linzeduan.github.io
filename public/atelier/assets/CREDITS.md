# Website assets

- `wood/`: ambientCG Wood051, 1K color / OpenGL normal / roughness. Source: https://ambientcg.com/view?id=Wood051 . CC0; https://docs.ambientcg.com/license/ .
- `fabric/`: ambientCG Fabric030, 1K color / OpenGL normal / roughness. Source: https://ambientcg.com/view?id=Fabric030 . Same CC0 license.
- `plant/`: Poly Haven Potted Plant 02, 1K glTF and textures. Source: https://polyhaven.com/a/potted_plant_02 . CC0; https://polyhaven.com/license . Exact download URLs preserved in `plant/source.json`.
- `garden-essay.webp`: original illustration generated with the built-in image generation tool for this site.
- `shelf-illustration.webp`: companion illustration generated using the preceding illustration as a style reference.
- `screen-preview.png`: screenshot of this prototype's empty public interface, used as the laptop's screen texture. Contains no private records.
- Window scenery and contact-shadow texture: original procedural canvas textures in `details.js`.
- Three.js and its loaders/utilities: MIT license, retained in `../vendor/LICENSE`.

All downloaded runtime assets are local. No third-party CDN or external asset endpoint is contacted by the prototype at runtime.
