# 大陆网络验证

此清单需要双方本人在真实手机和网络完成。本机开发、代理下 GitHub 成功、国外探测、ping 或打开官网都不能代替。

## 诊断阶段

设置页面的网络诊断仅访问指定的 Worker 地址，不存真实答案；未设置地址时按钮不得伪造成功。公共健康检查测试连通性；授权探针验证带令牌请求及 D1 写入/读取；探针密钥不进入前端构建或持久存储，由测试者临时输入。

两人、常用 Wi-Fi/移动网络、至少两个时段，各连续 10 轮。每轮记录健康请求、授权写读、耗时、错误码、设备及网络标签。正文仅固定测试标记，服务端限制为每个探针用户一行。错误授权必须 401。

门槛：十轮每轮三项检查完整，核心操作各 10/10 成功，负向凭证均被正确拒绝；20 次连通性和授权写读请求的 95% 耗时不超过 5 秒。持续阻断失败。飞行模式后恢复、关闭重开后重新验证。诊断阶段不代表生产认证已通过，生产认证完成后另测登录、会话过期/续期和一小时后的恢复，密码恢复及安装后的 PWA。

测试前选择 A/B 和当前网络，并由本人勾选确认已关闭 VPN/代理。页面无法自动证明直连；没有本人确认时，即使请求全部成功，也不标记为直连通过。服务端返回的探针身份必须与所选测试者一致。

每份 JSON 报告采用 schemaVersion=2，固定测试开始时的服务地址、测试者、网络、直连声明、浏览器名称及是否独立 PWA；同时保留开始/结束时间、轮次、每项耗时和结果。修改表单不改变旧报告。不会包含密钥、IP 或完整 User-Agent。停止或离开页面立即中止当前请求，已取消/缺项的报告不能算通过；单请求最多 10 秒。

报告是客户端生成的单次测试证据，不能据此单独宣布生产网络通过；还需覆盖双方、两类网络、不同时段及恢复场景。旧 schemaVersion=1 报告未固定完整上下文，不能直接作为新门槛的验收记录，请重新运行测试。
