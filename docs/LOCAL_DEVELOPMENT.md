# 本地版本使用说明

版本：0.2.1-local。无需 Cloudflare、Firebase 账号或付费服务。

## 打开应用

当前 Windows 工作区已安装依赖。双击根目录的 `启动本地版.cmd`，保持终端窗口开启，然后访问 http://127.0.0.1:5173 。也可在根目录执行：

```sh
node scripts/local-dev.mjs
```

启动器同时运行 Vite（5173）和本机 API（8788）；端口占用会报错并退出，不会悄悄切到另一个地址。需要 Node.js 24 或更新版本。首次从 GitHub 下载源码则先安装 Node 和 pnpm，然后执行 `pnpm install --frozen-lockfile`。

首次页面要求创建 A、B 两个账号，称呼自定，密码各自至少 12 个字符，没有默认密码。设置只允许执行一次；删除账号不会重新开放注册。当前没有邮件找回密码，妥善保管密码。

## 两个独立会话

1. 在普通浏览器窗口登录 A，创建空间，生成邀请码。
2. 在另一个浏览器、独立浏览器配置或无痕窗口登录 B，粘贴邀请码加入。普通浏览器的两个标签页通常共享登录 Cookie，不能当成两个人的独立会话。
3. 双方看到按上海日期安排的同一道题。各自作答，等待“已保存在本机”，再正式提交。
4. 只有双方正式提交，服务端才会返回对方的共享答案。个人笔记和后续私人修改始终不共享。解锁后在交集留言或追问。
5. 撤回会永久关闭这一轮共享；需要再次共享时从题库发起新的共同问答。自由题必须由对方接受，高敏感题要求明确确认。旧题重答创建独立的私人记录。

历史与题库支持补答和选题；我的宇宙支持检索、私人笔记、版本回顾和重答；设置支持主题、导出、改密码、退出、解散和本人账号注销。

## 保存与异常

草稿在停止输入约 0.5 秒后发送，只有服务确认成功才显示“已保存在本机”。刷新和重启服务保留已保存数据；未保存的输入仅在当前页面内存中，关闭浏览器仍可能丢失。离开页面会提示尚未保存；浏览器或操作系统异常关闭无法保证弹出提示。

保存失败时可以重试或下载未同步草稿。版本冲突不会自动覆盖；先下载当前副本，再确认读取服务中的新版本。会话失效会要求当前账号重新登录，期间保留输入；重新登录后重试保存。改密码使该账号所有旧会话失效。

留言发送后若刷新失败，恢复连接后可重试，不会重复写入同一条。发送期间可以继续输入，新的文字不会被上一条的完成响应清空；交集里的当前轮次也不会因为另一轮刚解锁而自动切换。

对方内容在页面进入后台或连接失效时隐藏，恢复后重新鉴权；前台每 5 秒刷新一次。服务端对撤回后的新读取立即拒绝，屏幕上已显示内容的收起可能有轮询延迟。已阅读、截图或已导出的副本无法追回。

## 数据位置与备份

默认数据库是项目目录下 `.local/between-answers.sqlite`，运行时可能同时存在 `-wal`、`-shm` 文件。它们和 JSON 导出均不进入 Git。

- 日常迁移：两个人分别登录，在设置“导出我的数据”，保存 JSON。导出包含本人答案、笔记、版本、共享快照、留言、相关轮次、跳过记录及引用题目，不含密码或会话。轮次信息让留言在解散后仍能对应原题，字段见 DATA_EXPORT.md。当前只提供导出，尚无 JSON 导入界面。
- 可选择额外导出目前仍获授权的对方共享内容；必须明确确认，且服务端重新检查授权。
- 整机恢复：先停止本地服务，确认端口 8788 已停止，再把整个 `.local` 目录复制到安全位置。不要只拷贝正在写入的主数据库而遗漏 WAL。恢复时也应先停服务，将原目录另行保留，再放回备份。整机备份含双方数据和登录凭证材料，应由双方信任的本机管理员保管。

删除本人记录会清除该记录的版本、笔记与共享正文并关闭相关共享；不删除对方自己的记录。注销删除本人的账号和记录；解散仅停止共享，双方个人数据均保留。这里的删除是数据库逻辑删除，不承诺从磁盘、系统备份或此前导出的副本中彻底擦除。

## 当前边界

服务仅监听 `127.0.0.1`，不会开放到局域网或公网；手机尺寸测试通过不等于手机能够连接这台电脑。两台异地手机同步、真机安装和云端数据恢复仍待后续阶段。不要通过改监听地址或端口转发把开发服务器作为生产服务。

本机管理员可以读取 SQLite 文件；V1 不做端到端加密。密码使用带随机盐的 scrypt 哈希，会话仅保存 token 哈希，浏览器使用 HttpOnly、SameSite=Strict Cookie。当前 HTTP Cookie 和 Node 认证适配仅用于本机，云端要独立完成 HTTPS、会话、跨域及认证恢复配置。

GitHub Pages 默认继续构建演示。`VITE_APP_MODE` 是公开构建开关，不是密钥；无需给本地模式填写 `.env`。原网络探针可保留，暂时不需要登录 Cloudflare。

## 开发与验证

```sh
pnpm check
pnpm test:e2e
pnpm test:local
```

`check` 包括题库原文校验、前端/探针/本地服务严格类型检查、单元及 HTTP 集成测试和演示构建。两组 Playwright 分别检查公开演示与真实本地双账号流程。本地浏览器测试的前端在 4175、API 在 8789，与正在使用的预览（5173/8788）隔离。测试只接受本次子进程自己的就绪信号，不复用已有 API；使用临时数据库和合成答案，不操作实际用户库。

服务实现放在 `server/`；浏览器 HTTP 适配在 `src/data/http/`，页面经统一控制器接入。未来云端可替换服务及会话适配，保留业务模型、页面和权限验收用例。
