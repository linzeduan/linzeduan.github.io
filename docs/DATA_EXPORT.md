# 本人 JSON 导出格式

来源：设置 → 导出我的数据。此文件可包含私人笔记，保存在用户自行选择的位置，不要提交 Git。

当前 `schemaVersion` 为 2，`source` 为 `local`。0.2.1-local 在相同格式下增加 `rounds` 和 `skipped` 字段，保留原有字段含义；读取 0.2.0-local 导出时，这两个字段可能不存在，读取方应兼容缺省值。

| 字段        | 内容                                                                                                                             |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| exportedAt  | 服务端导出时间，UTC ISO 字符串                                                                                                   |
| user        | 本人 id、称呼，无密码或会话                                                                                                      |
| entries     | 本人回答和私人笔记、原题 ID、创建/修改时间、版本号、可选 roundId                                                                 |
| revisions   | 本人每次实际保存的答案/笔记版本及时间，entryId 关联 entries                                                                      |
| submissions | 本人提交时冻结的正文和版本、提交/撤回时间，round_id 关联 rounds                                                                  |
| comments    | 本人留言/追问、时间、原回复目标 ID，round_id 关联 rounds                                                                         |
| rounds      | 本人记录所引用的轮次：roundId、questionId、spaceId、date、kind、planVersion、spaceStatus、closed；不含对方正文、草稿、笔记或凭证 |
| skipped     | 本人跳过的 questionId 数组                                                                                                       |
| questions   | 以上记录、轮次、跳过记录涉及的原题、编号及分类元数据                                                                             |
| shared      | 默认缺省；用户明确选择后，仅加入此刻仍解锁的对方共享答案与交流                                                                   |

`date` 使用上海自然日 `YYYY-MM-DD`；其余时间使用 UTC ISO。`submissions` 与 `comments` 保留最初导出的 SQL 字段命名，以保持兼容；新增的轮次元数据使用前端业务字段命名。

迁移关联步骤：用 `rounds[].roundId` 建立索引，将留言的 `round_id` 映射到 `questionId`，再到 `questions[].questionId` 查原题。即使自己的答案已经删除，只要本人的留言仍保留，这段关联也会导出。未引用的轮次及对方自己的记录不会因为导出关联信息而加入。

留言的 `reply_to` 可能引用对方的留言。默认本人导出不会因此复制对方正文；不要把未包含的目标视为数据丢失，也不要猜测其内容。空间解散或共享撤回后，`shared` 不再包含已失效授权的内容，本人记录与题目关联继续保留。

导出不包含身份凭证、邀请码、整份空间成员名单或完整推荐日程，不是可直接覆盖数据库的备份。当前没有导入界面；整机恢复应依 LOCAL_DEVELOPMENT.md 的停服备份流程。读取旧版导出缺失的轮次信息时，不应推测留言属于哪道题；有原本地库时可重新导出补齐。
