# 生活系统

生活系统是侧栏可展开分组：人生信念、投资纪律、富裕人生。右侧由同一个中台外壳原生渲染，使用统一设计变量、深浅主题、整页滚动和移动端布局；不使用 iframe。

## 模块边界

- src/modules/beliefs/：人生信念结构化原文及入口，共 5 篇、18 条。保留前言和结语。
- src/modules/discipline/：投资纪律结构化原文及入口，共 6 篇、25 个内容块。
- src/modules/systems/：模块目录、共用阅读交互和样式。阅读页支持章节跳转、随机阅读、打印和原则复制。
- src/modules/wealth/：富裕人生原生账本界面及独立数据模型。账户、月份、趋势、备份恢复、CSV 与删除月份独立实现。
- public/modules/：旧独立页面 URL 的跳转兼容页，不再保留旧页面样式和运行逻辑。

原始 HTML 保留在工作区「源文件」，不修改、不上传。公开内容的初始账本为空，不包含真实账户余额。

## 数据兼容

沿用 fuli-monthly-assets-v1 存储键和 version:1 JSON 格式。已有网站账本自动读取，旧复利人生 JSON 备份可通过恢复备份导入；file:// 原页仍需先导出再导入。保存成功后才提交界面状态。读取异常时禁止覆盖原记录，导入新备份须明确确认。切换月份不会修改其他月份；新月份复制最近一期并标记待更新。

## 验证

node scripts/check.mjs 覆盖原文数量、无 iframe、金额校验、历史格式兼容、月份隔离与非法备份。scripts/browser-check.mjs 使用 Playwright（PLAYWRIGHT_MODULE 可指定安装路径，BROWSER_CHANNEL 默认 msedge，QA_DIR 指定截图目录），在本地服务运行时验证侧栏、阅读、账本编辑与刷新、新月份、历史图表、备份导入、损坏数据保护、深色模式和窄屏布局。
