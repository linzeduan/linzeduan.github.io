公开资产页使用动态当前月份的空账本，不包含原文件的账户名称和余额。用户通过新增账户开始使用，或通过历史页面恢复原页面导出的 JSON 备份。沿用 fuli-monthly-assets-v1 存储格式，备份不上传服务器。file:// 原始页面与网站存储不互通，需手动导出再导入。不得将真实余额重新写入公开 HTML 的初始数据。

投资纪律原本链接的「复利人生-资产配置.html」未提供；现有入口改为资产记录，并注明配置参数页待补充。没有推导或改变投资原则。
