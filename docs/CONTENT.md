# 内容与数据边界

当前主导航为总览、健康、投资、学习、我的原则。“项目”“灵感”“近况”不再作为产品模块，原有浏览器内容保留在 zhongtai.records.v1 中，不展示或自动重分类。

健康、投资、学习使用 health、investment、learning 类型。原存储键内的其他记录不会被新增操作删除。损坏的 JSON 会阻止保存，避免覆盖无法读取的内容。当前仅支持新增，暂不支持编辑、删除、备份和跨设备同步。

每日小事保存在 zhongtai.daily.v1，按 Asia/Shanghai 日期重置，勾选可撤销。

人生信念保留 5 篇、18 条，投资纪律保留 6 篇原文，仍为原生阅读组件，不使用 iframe。参考文件只用于内容和视觉参考，不修改或上传源 HTML。

“富裕人生”从导航、目录和路由注册中隐藏，保留 src/modules/wealth 的模型与代码，不修改 fuli-monthly-assets-v1 账本数据。旧账本 URL 跳转至投资主页。今后重新启用应明确恢复路由和入口。

UI 的统计只读取当前浏览器真实记录，不填充虚构资产、运动或学习数据。初次使用显示明确的记录入口。
