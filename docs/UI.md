# 界面与动效约定

## 已确认方向

最新方向：现代 3D 房间作为入口，内容页采用个人花园式排版。用户参考 Henry Heffernan 的空间入场体验和 Maggie Appleton 花园的层次感，明确要求进入后固定全屏界面，只有点击退出按钮才返回场景；鼠标越过屏幕边缘不能退出。该方向取代此前银白科技感首页的决定。保留左侧导航、主题、记录与阅读能力。

## 视觉

内容背景 #f6f5f1，面板 #fffefa，纸色配柔和绿；深色背景 #171c19。大标题采用本地衬线字体，正文和操作采用系统无衬线字体。首页通过多列不同高度的图文、文字、项目及日常模块建立层次，桌面三列、平板两列、手机单列。内容卡片使用细边框和较小圆角，导航和操作保留清晰的 iOS 控件习惯。

首页展示原则、真实记录、当前项目、唯一优先事项和日常行动；每日进度用小型数字与进度环表示。健康、投资、学习入口收为主题栏。记录数量和进度来自浏览器数据，不展示虚构指标。主题页与阅读页沿用统一视觉变量。

## 动效实现

原有交互动效集中在 src/components/motion.js 和 src/styles/motion.css。房间入口由 src/components/arrival.js 与 src/styles/arrival.css 实现，使用原生 CSS 透视与 3D 平面，无新增依赖、模型或外部纹理。

- 侧栏导航：选中底板以 250ms 无回弹曲线轻滑，内容区仅做 180ms 轻微透明度过渡；不触发整页快照、位移、模糊或标题形变。根节点预留滚动条位置，避免不同页面高度导致横向跳动。
- 手机导航与分类：独立底板通过几何测量和 Web Animations 弹性滑动，支持中途打断。
- 首页主题卡片：直接点击卡片且支持 View Transitions 时，共享 domain-surface 和 domain-title 连续展开。侧栏、底栏、普通链接和浏览器历史切换均走平稳的内容过渡。快速切换会跳过未完成转场，并清理临时名称。
- 记录弹窗：从触发按钮的位置和尺寸展开，内容错峰进入；关闭、Escape 和点击遮罩时收回。保留原生 dialog 的焦点和键盘行为。
- 完成反馈：勾选描线、弹性缩放、短暂粒子和进度环联动。粒子只响应完成动作，结束后删除。
- 主题切换：从点击位置展开圆形揭幕。支持连续切换。
- 桌面指针：主题入口轻微倾斜；房间在桌面指针移动时有小幅视角变化，指针不改变场景模式。触屏不启用悬浮追踪。

房间内含现代笔记本、木桌、台灯、书、绿植与抽象挂画。点击笔记本屏幕或“打开花园”执行约 1150ms 镜头推进并进入全屏界面。右上角“回到房间”可重新打开场景，之后回到原页面、滚动位置与焦点。Escape 与“直接进入”均可进入内容。每个标签页首次访问首页显示房间，深链接直达内容；sessionStorage 不可用时仍可操作。

其他单次动效约 180–720ms。用户开启 prefers-reduced-motion 时，跳过转场、粒子与位移动画；运行中切换偏好会取消进行中的动画。不支持 View Transitions 时，保留普通页面切换与基础进入动画。

## 验证

scripts/browser-check.mjs 检查三类记录、存储、阅读、主题、导航及 320/390/768/1024 宽度。
scripts/browser-room.mjs 检查屏幕点击进入、镜头推进、边缘移动不退出、按钮返回、页面/滚动/数据保留、重复访问、深浅主题、320/390/768/横屏布局、减少动态效果及动画 API 回退。
scripts/check-motion.mjs 额外检查共享转场、快速导航、粒子回收、弹窗取消及焦点恢复、触屏减少动态效果和 API 缺失时的回退。

保持现有存储键，账本继续隐藏，不增加第三方服务或远程资源依赖。
