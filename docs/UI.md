# 界面设计约定

## 方向

围绕健康、投资和学习的个人生活工作台。延续“一个人的林地”的自然气质，以深绿侧栏、浅色内容区、柔和主题色和中文衬线阅读形成识别。首页用于进入主题、完成今日小事和回看记录；长文使用连续阅读布局。

## 色彩与排版

- 背景 #f4f5f0，内容面板 #fffefa，正文 #253b32，辅助文字 #627066。
- 侧栏 #203f34，主要操作 #365f4b；健康草绿、投资麦色、学习雾青。
- 通过 base.css 的语义变量适配深色模式，避免在共用组件中硬编码浅色面板。
- 界面正文用系统无衬线字体；主题标题和长文使用中文衬线字体。主要界面文字为 13–16px，辅助信息为 11–12px，阅读正文桌面 15px、手机 14px。
- 通用面板圆角 18px、按钮 9px；仅有层级意义的区域使用背景面板。避免增加无用途的数字、图表和装饰性标签。

## 页面与交互

- 首页：林地插画、三个主题入口、今日小事、原则入口、最近记录。完成进度来自当日真实勾选，记录数来自当前浏览器。
- 主题页：主题封面、记录主栏、原则阅读和思考提示。健康页只显示运动相关的每日小事。
- 阅读页：桌面右侧固定目录，窄屏横向滚动章节导航。当前章节随滚动标识。保留随机阅读、复制和打印。
- 记录弹窗：分类分段按钮、标题、正文、保存反馈。长记录使用原生 details 展开全文。
- 手机：底部四个主入口，侧栏抽屉用于全部导航和主题切换。抽屉关闭时 inert，打开时支持焦点循环、Escape 与遮罩关闭。
- 尊重 prefers-reduced-motion；深色主题在初次样式加载前恢复，避免闪烁。

## 实现边界

原生 HTML/CSS/ES Modules。插画与主题图形由 garden.js 生成 SVG，不依赖远程字体、图片和运行库。模块按职责分文件，样式通过语义变量统一。此次 UI 升级不改变记录存储键，也不恢复已隐藏的账本。
