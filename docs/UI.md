# 界面与动效约定

## 已确认方向

用户偏好 iOS 风格的简约、高级感和科技感，同时欣赏有表现力的交互动效。设计原则为“静态极简，动态惊艳”：银白与石墨为基础，系统无衬线字体，健康粉、投资蓝、学习橙仅用于识别和状态。取消田园插画和衬线标题。

## 视觉

背景 #f5f5f7，面板 #ffffff，正文 #1d1d1f，辅助文字 #6e6e73，交互强调 #007aff。深色模式使用接近黑色的背景和石墨面板。主要面板圆角 24px，操作控件 12–13px，重要记录按钮使用胶囊形。透明材质用于导航、浮动底栏、反馈与焦点球，普通内容保持可读性。

首页焦点球展示真实的每日完成数量，三个卫星按钮进入对应主题。记录数量和进度来自浏览器数据，不展示虚构指标。主题页与阅读页沿用统一视觉变量。

## 动效实现

动效集中在 src/components/motion.js 和 src/styles/motion.css，不引入运行时依赖。

- 侧栏导航：选中底板以 250ms 无回弹曲线轻滑，内容区仅做 180ms 轻微透明度过渡；不触发整页快照、位移、模糊或标题形变。根节点预留滚动条位置，避免不同页面高度导致横向跳动。
- 手机导航与分类：独立底板通过几何测量和 Web Animations 弹性滑动，支持中途打断。
- 首页主题卡片：直接点击卡片且支持 View Transitions 时，共享 domain-surface 和 domain-title 连续展开。侧栏、底栏、普通链接和浏览器历史切换均走平稳的内容过渡。快速切换会跳过未完成转场，并清理临时名称。
- 记录弹窗：从触发按钮的位置和尺寸展开，内容错峰进入；关闭、Escape 和点击遮罩时收回。保留原生 dialog 的焦点和键盘行为。
- 完成反馈：勾选描线、弹性缩放、短暂粒子和进度环联动。粒子只响应完成动作，结束后删除。
- 主题切换：从点击位置展开圆形揭幕。支持连续切换。
- 桌面指针：主题卡片轻微倾斜并响应局部光照，焦点球有轻微视差；触屏不启用悬浮追踪。

单次动效约 180–720ms。用户开启 prefers-reduced-motion 时，跳过转场、粒子与位移动画；运行中切换偏好会取消进行中的动画。不支持 View Transitions 时，保留普通页面切换与基础进入动画。

## 验证

scripts/browser-check.mjs 检查三类记录、存储、阅读、主题、导航及 320/390/768/1024 宽度。
scripts/check-motion.mjs 额外检查共享转场、快速导航、粒子回收、弹窗取消及焦点恢复、触屏减少动态效果和 API 缺失时的回退。

保持现有存储键，账本继续隐藏，不增加第三方服务或远程资源依赖。
