# 0.2.0-local 阶段验收

2026-10-17。用户确认先完成本地版本，云端账号和直连验证后置。开发分支 `feat/local-v1`；公开站点保持 0.1.1 演示，暂不部署真实私人服务。

## 已完成

- 本机 Node HTTP + SQLite 持久保存，浏览器通过同源 API 接入，公开演示和真实本地数据适配独立装配。
- 首次只建 A、B 两个账号，自定密码、scrypt 哈希、HttpOnly Cookie、会话失效、登录频率限制、改密码和本人注销。
- 随机单次邀请、24 小时有效、最多两人、活动空间隔离；解散保留个人记录。
- 上海自然日同题、冻结推荐计划、补答、跳过、自由题双向接受及高敏感题明确确认。
- 私人草稿和笔记自动保存、乐观版本检查、每次实际保存的历史版本、重答保留旧记录。
- 正式提交冻结正文快照，服务端双向解锁；私人笔记和后续编辑不泄露。解锁后留言、追问、本人留言删除。
- 撤回、记录删除、空间解散后拒绝对方新读取；本人数据仍可管理和导出。
- 默认导出本人可迁移 JSON，可确认加入仍获授权的对方共享内容。删除、解散、改密码、注销均有确认。
- 本机保存状态、失败重试、未同步草稿下载、冲突保留、登录过期重新认证；单命令及 Windows 双击启动入口。

## 限制与下一步

本阶段不提供异地同步。API 仅监听 loopback；不得把开发服务器转发到公网。云端认证/恢复、真实域名直连、云备份、真机安装仍未验收。

未保存的输入只在当前页面内存中，浏览器异常关闭可能丢失；JSON 暂无导入界面，没有邮件找回密码。本机数据库不加密，信任本机管理员；逻辑删除不擦除既有备份或磁盘残留。撤回阻止后续读取，已阅读或导出的副本不能追回。

没有新增运行依赖、付费账号、队列或独立状态管理库。Native SQLite 仅为本地适配，未来保留关系模型和权限测试，按实际云平台实现对应事务与认证，不承诺 Node 密码实现能直接运行在 Worker。

优先级：本地试用修正 → 用户准备云账号后做双方实际网络验证 → 选型及云适配 → 恢复、备份和同等权限回归 → 真机 PWA → 私人使用。V2/V3 保持后置。
