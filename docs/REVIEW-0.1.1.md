# 0.1.1 网络验证复核

日期：2026-10-17。

## 本次修正

0.1.0 的网络检查在离开页面后仍可能继续发送请求，且结束后修改网络标签会影响旧结果的导出上下文。这会消耗额外请求并影响验收可信度。

- 每轮检查与单请求共享取消信号；手动停止和组件卸载立即中止当前请求，不再发后续请求。十秒超时可区分于用户取消。
- 每次运行只复制允许导出的元数据，固定网络、测试者、服务地址和时段。密钥仅用于请求，完成后清空，不进入报告、日志或浏览器存储。
- 验证服务标识、固定数据库标记和 A/B 身份，负向授权必须返回探针的 unauthorized 响应；错误响应不把任意服务端文本写入导出。
- 每份报告包含十轮覆盖情况、成功数和核心请求 P95；中止、慢连接、未确认直连和失败分开呈现，不把 30 次 HTTP 成功直接当作网络验收。
- 报告 schemaVersion 升为 2，旧报告需重测；设置中的版本号由 package.json 读取。

## 验证

- 22 项单测：新增取消/超时、覆盖度、延迟、服务与身份匹配、报告元数据冻结及不含秘密的检查。
- 16 项桌面与手机尺寸浏览器测试：新增实际跨域访问本地 Worker+D1、报告下载检查、错配身份拒绝、手动停止与离开页面的真实 fetch 取消。
- 保留原有题库校验、前后端严格类型检查、PWA 旧缓存迁移和生产构建验证。
