# 0.2.1-local 数据可靠性修正

2026-10-17。继续按“先本地、稍后云端”推进，保持开发分支和 PR #3 草稿，不发布私人云服务。

## 问题与结果

本地 E2E 原先与用户预览共用 8788，并以健康检查判断就绪。如果预览已开启，测试子进程可能启动失败，却继续请求用户库。本版本将测试 API 改为 8789，测试前端独立反代，并先等待本次子进程自己的启动信号；端口冲突直接失败，不复用已有服务。清理放入 finally，浏览器关闭失败也会停掉测试 API。

答案提交、留言 POST 已成功但后续刷新失败时，原控制器过早释放幂等编号。现在直到刷新完成才释放；重试沿用原编号，避免重复留言或已提交快照被误报冲突。

发送留言期间的新输入原先可能被完成响应清空。现在发送期间防重复点击，以编辑代次判断是否清空，保留后续文字；当前问答轮次固定到用户进入或选择的那一轮，新轮次解锁不会悄悄改变草稿归属。无效轮次链接明确显示无法打开。

JSON 导出原先只有留言的 round_id，缺少其与题目的关联；答案删除后，迁移无法判断留言属于哪题。现在增加本人记录所引用的 rounds 元数据和 skipped，以及相关原题。解散后仍保留关联，授权失效不加入对方正文，原有字段保持兼容。见 DATA_EXPORT.md。

## 验证

- 42 项单元/HTTP 测试通过：新增 POST 确认后刷新失败时的留言及答案重试，以及删除答案、空间解散后的本人导出关联与隐私隔离。
- 400 题原文校验、前端/探针/本地服务严格类型检查及构建通过；16 项公开演示浏览器回归通过。
- 8 项本地浏览器测试通过（桌面与手机尺寸各 4 项）。新增真实服务下的失败刷新重试、唯一留言、发送期间继续输入、另一轮解锁时草稿不换题、无效轮次链接；既有绑定、权限、保存冲突、重新鉴权、重答及服务重启流程仍通过。
- 测试与实际预览同时运行，使用不同端口和临时数据库；未停止用户预览或把测试答案写入默认本地库。

## 边界

不增加运行依赖、付费服务或数据库表。新增导出字段是可迁移上下文，不提供 JSON 导入或整库恢复。生产认证、异地同步、云备份及真机 PWA 仍待云端阶段，不将本地验收当作正式上线完成。
