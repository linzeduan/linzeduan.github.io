# 答案之间 产品需求

Slogan：我们各自回答人生，也在答案之间慢慢认识彼此。

## 目标与边界

仅供两位朋友使用的私人双人问答 PWA。个人记录与认识彼此同等重要，不设契合度、不默认恋爱关系、不用连续打卡施压。优先级为隐私安全、可靠性、体验、视觉、扩展。

已确认：信任持有云平台管理权限的人，V1 不提供端到端加密；大陆日常 Wi-Fi 和移动网络必须直连；撤回或解散后停止对方的后续读取，截图和已导出副本不能追回；免费方案不接受宣传续期或闲置后人工恢复。

## V1 功能与验收

- 两个预设账号，随机一次性邀请码绑定，每人至多一个活动空间，每空间至多两人；成员固定，解散不可恢复。
- Asia/Shanghai 自然日同题。固定版本日程，漏答可补，跳过无惩罚；高敏感题不默认推送。
- 私人草稿、正式提交、双向解锁。对方正文只能由服务端在双方均提交且未撤回时返回；不得前端隐藏代替鉴权。
- 正式共享快照冻结；私人答案可继续编辑。重新共享形成新轮次，个人重答不覆盖旧记录。
- 解锁后阅读双方答案，留言、追问和本人留言删除；支持纯文本。
- 我的宇宙可按日期、主题和关键词检索；笔记仅本人可读，记录创建、修改和提交时间。
- JSON 导出包含 schemaVersion、题目、本人答案、版本、笔记和留言；对方数据仅在仍获授权时明确选择导出。
- 删除本人记录前撤回相关共享；解散仅关闭共享，不删除个人记录；账号注销先清理数据再删除身份。
- 浅深主题、手机阅读、PWA 安装、明确网络及保存状态；不显示虚假的同步成功。

## 信息架构

底部导航：今日、我的宇宙、我们的交集。档案从宇宙及今日进入；设置由右上角进入。本地模式提供账号初始化、登录、重新鉴权和绑定页，演示模式明确标注模拟身份。小游戏不在 V1 导航放空入口。

今日：题目与原编号、编辑、笔记、保存、正式提交、跳过、自由选题。
宇宙：本人记录列表、筛选、历史版本和重答。
交集：轮次状态、解锁答案、留言与追问。
档案：按日期补答、题库选题。
设置：主题、空间、数据导出、删除、撤回及解散。

完整状态：加载、无内容、未绑定、等待成员、未提交、保存中、未同步、提交待确认、等待对方、对方已提交、已解锁、已跳过、已撤回、已解散、网络失败、权限失效。不得短暂闪现无权读取的正文。

## 设计

暖纸白、墨色、鼠尾草绿，中文宋体用于主要阅读，无衬线用于操作。克制留白和书信感，无恋爱暗示。手机单列答案、桌面双列；适配安全区域、键盘、减少动态效果。无外部字体或图标 CDN。

## 后续

V2：猜对方答案、记忆拼图、时间胶囊、成长对比、阶段纪念册。V3：自创题、轮流出题、媒体记录。均不得成为 V1 的依赖。

## 预览限制

阶段 1 为使用合成内容的演示模式，在内存中模拟双方，刷新丢弃编辑。界面必须清晰说明不能用于真实私密记录，不能把演示状态当成生产安全证据。

0.2.0-local 按用户最新选择，先提供本机真实账号和持久记录，服务端执行解锁；两个人用独立浏览器会话验证。数据位于本机 SQLite，不向 GitHub 或云端同步。跨设备、云端恢复及真机安装仍待后续上线验收。
